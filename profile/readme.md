## Welcome!
A library of resource and data packs for Minecraft.

### What are these?
These repositories contain custom resource and data packs that have been created for Minecraft. Each repository has a description of what it adds or changes in the game. These are not necessary to play the game but have been created as additional features that are not in the base game by default. If a feature actually gets added to the game, the repository will be archived appropriately.

### How do I download these?
1. Find the repository for the pack you want to download
2. Check the version of Minecraft you are playing, and compare it to the repository branch
3. Look for the releases header on the right and click on the version
4. Download the asset

#### For resource packs:
1. Navigate to the `resourcepacks` folder
2. Find the downloaded file, and drag and drop the file into the `resourcepacks` folder
3. [Load the resource pack](https://minecraft.wiki/w/Tutorial:Loading_a_resource_pack)

#### For data packs:
1. Navigate to the `datapacks` folder for your world
2. Find the downloaded file, and drag and drop the file into the `datapacks` folder
3. Open the world


### Troubleshooting:
#### What type of pack is it?
Resource packs need to go in the `resourcepacks` folder inside where your `.minecraft` folder is.\
Data packs need to go in the `datapacks` folder inside your world folder.

| Operating system | Default path                              |
|:----------------:|:-----------------------------------------:|
| Windows          | `%APPDATA%\.minecraft`                    |
| macOS            | `~/Library/Application Support/minecraft` |
| Linux            | `~/.minecraft`                            |
|                  |                                           |


#### Is it loaded in game?
To see if you have data packs loaded:
1. Load the world
2. Issue the command: `/datapack list`

\
If you do not see any of the selected packs in this list, you may have placed them in the wrong folder. Ensure they are in the appropriate directory: `/saves/<WORLD_NAME>/datapacks/`\
\
If the world doesn't load, it is possible you may have the wrong version. Check the version of your game and the pack you are downloading and make sure they match. If a new game version is released, it is possible the pack is not available for that version yet.\
\
If the world doesn't load due to errors: remove the faulty pack, re-download it, and follow the steps again.\
\
If the explanation was not helpful, have a look [here](https://minecraft.wiki/w/Data_pack) for more support.

### Do I need to credit?
No, the license for all of these repositories are [CC0](https://creativecommons.org/public-domain/cc0/). Feel free to download and share these packs. You can compile these into big packs or even extend these ideas in your own way.

### Can I contribute?
We are not looking for contributors currently.\
If you have been involved or contributed towards a pack, your preferred username will be in the meta key under `authors` in the `pack.mcmeta` file.

### Can I make requests?
This organisation is **not** a request page for packs.\
It is possible that some of the ideas and packs posted here have been done before or more efficiently.
