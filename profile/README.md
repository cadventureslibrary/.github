## What are these repositories?
These repositories are for storing custom resource packs and data packs created for Minecraft. Each resource and data pack has its own repository which will have branches for the appropriate version it is for.

These packs have been created for fun and are free for people to take if they please.


## How do I use these packs?
1. Find the appropriate repository you want to download
2. Check the version of Minecraft you are playing and switch to the appropriate branch in the repository
3. Click on the 'code' button and download the ZIP
4. Extract the contents of the ZIP to a folder
5. Create a new world in Minecraft
6. Switch to the 'more' tab and select the 'data packs' button
7. Click on 'open pack folder'
8. Select the packs you want to use from the unzipped repository and copy them to the directory
9. In game, click on the arrows of the packs you want to move them to the right side
10. Click 'done' and let the packs validate
11. Create the world


## Troubleshooting
To see if you have the datapacks loaded, type the command `/datapack list`. If the datapacks do not appear in the list, check you have followed the steps correctly.

### The pack is not validating
If the packs do not validate, please check that you have downloaded the correct version of the branch. Each branch will be for a specific version of the game. Some packs may be cross-compatible but do not assume this.
If there is no branch available for the version you are playing, there are no data packs available at that time.

If the explanation was not helpful, have a look [here](https://minecraft.wiki/w/Data_pack) for more support.

## Can I contribute?
This repository is a storage for data packs. I am not looking for contributors currently. This repository is **not** a request page for data packs either.

If you have contributed towards a pack, your username will be in the 'authors' meta key in `pack.mcmeta` file.
